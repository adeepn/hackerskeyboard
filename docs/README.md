# Hacker's Keyboard v2

Эта папка содержит план модернизации Hacker's Keyboard для актуального Android
без потери функциональности. Рабочая ветка программы — `v2`; `master` остаётся
контрольной точкой версии 1.x.

## Целевое состояние v2

- воспроизводимая сборка на JDK 17 с Gradle wrapper;
- `compileSdk` и `targetSdk` 36;
- публикационная совместимость с требованиями Google Play 2026;
- AndroidX вместо старой Support Library;
- исправная работа на Android 7–16 при `minSdk 24` согласно ADR-0001;
- сохранение раскладок, compose/dead keys, модификаторов, popup-клавиш,
  словарей, подсказок и терминальных сценариев;
- тесты, позволяющие постепенно улучшать архитектуру и внедрять Kotlin.

## Правило принятия решений

Сначала обеспечивается измеримая функциональная совместимость, затем проводится
рефакторинг. Сам факт использования нового языка или UI toolkit не считается
улучшением, если он не снижает стоимость сопровождения либо не устраняет
конкретную проблему.

## Основная ветка

`v2` является основной интеграционной веткой проекта. Все рабочие ветки
создаются от актуальной `v2`, все PR направляются в `v2`. Ветка `master`
сохраняется как историческая база v1 и не используется для новой разработки.

Актуальность внешних требований в этих документах зафиксирована на 10 августа
2026 года. Перед публикацией нужно повторно проверить официальные требования
Android и Google Play.
